# Gayatri Giri — Portfolio

A responsive personal portfolio highlighting my cybersecurity projects, hackathon builds, and independent projects.

## Project categories

- **Cybersecurity:** NetShield, VAULTline, Polybius Cipher Tool, NetVelocity Speed Tester
- **Hackathon:** MetroCert, Hybrdcast, SIH, SIH Site, HACKATHON-1
- **Personal:** SpendSmart AI, VASTUPRO, CODE-ReD, portfolio website

## Built with

- HTML5
- CSS3 (responsive layout, custom properties, reduced-motion support)
- Vanilla JavaScript (decorative petal animation)
- Google Fonts

## Run locally

Open `index.html` in a browser, or serve the folder with any static HTTP server.
